Welcome to the repository for the **[Polyglutamine Disorders Database (PolyQ Database)](https://polyq.pt/)**. 

This project serves as a centralized, comprehensive database dedicated to Polyglutamine (PolyQ) diseases—a group of neurodegenerative disorders caused by an expanded cytosine-adenine-guanine (CAG) trinucleotide repeat.

## 🔬 About the Project

The primary **objective** of the PolyQ Database is to provide structured, accessible, and scientifically accurate information on the **9 known distinct diseases** that result from an abnormal increase in CAG triplets. 

Polyglutamine diseases are hereditary neurodegenerative conditions. By aggregating data on these specific disorders, this platform acts as a high-value resource for geneticists, neurologists, researchers, and students.

### The 9 PolyQ Diseases Featured:
The platform structures data around the nine recognized polyglutamine expansion disorders, which include:
- Huntington's Disease (HD)
- Spinocerebellar Ataxias (SCA 1, 2, 3, 6, 7, 17)
- Dentatorubral-pallidoluysian atrophy (DRPLA)
- Spinal and bulbar muscular atrophy (SBMA / Kennedy Disease)
